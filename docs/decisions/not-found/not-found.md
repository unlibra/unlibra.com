# 404 ページのデザイン変更の判断ログ（not-found）

計画：`not-found/plan.md`。ここには、計画とユーザーの指示に書かれていない判断を書く。

2026-10-28 に表記を英語に変えた（見出しと `<title>` は「Page not found」、ボタンは「Back to top」。`docs/decisions/i18n/` I18N-6）。下の日本語の文言と `<title>` の記述は、その前のもの。

## NF-1 素材：元の SVG を2つに分けて置いた

- 決めたこと：元の SVG（`%TEMP%\claude\inbox\planets.svg`）から、次の2つのファイルを作って `src/assets/not-found/` に置いた。どちらも、取り除いた部分のほかは元のまま（`width="512" height="512"` は外した）。DiceBear の生成コメントとメタデータ（DiceBear、CC0）は残し、何を除いたかのコメントを足した
  - `planet.svg`：惑星（円盤、地表、陰、環、衛星2つ）とアニメーション（`<style>`、`prefers-reduced-motion: no-preference` のときだけ動く）。背景の `rect` と星 12個（定義と `<use>`）を除いた
  - `stars.svg`：背景の `rect`（`#282c34`）と星 12個。惑星とアニメーションの定義と `<use>` を除いた
- ページでは、惑星を CSS のアニメーションが効くようにインラインで出し（`?raw` と `set:html`）、星を `main` の背景のタイル（画面の中央から繰り返す）にした
- タイルの大きさ（レビューの推奨の指摘を受けて変えた）：最初は惑星の箱と同じ大きさにして、惑星のまわりの星を元の SVG と同じ並びにしていた。惑星の大きさが画面で変わると、星の大きさと間隔まで変わってしまうので、どの画面でも同じ `16rem`（256px）にした。星の点は直径 3〜4px ほど。惑星のまわりの星の並びは、元の SVG とは一致しなくなった
- LICENSE 第2節の DiceBear の項に2つのファイルを足し、見出しを `DiceBear "Shapes" and "Planets"` にした
- 他の選択肢：画面全体に別の乱数で星を散らす（元の SVG にない星になる）。元の SVG を `<img>` で中央に置き、背景だけ `#282c34` にする（星が中央の正方形にしかない）
- 戻すときの作業：`src/assets/not-found/` と LICENSE の2行を消す

## NF-2 星のまたたき：元の SVG のとおり、またたかない

- 見つけたこと：元の SVG の `<style>` には、またたきの CSS（`.dbpa-tw-medium`・`.dbpa-tw-large`・`.dbpa-tw-sparkle`）があるが、どの星にもそのクラスが付いていない。元の SVG を開いても、動くのは地表と衛星の回転だけで、星はまたたかない
- 決めたこと：計画の「星の見た目とまたたきは元の SVG に合わせる」に従い、星は動かさない（元のまま）。またたきの CSS は `planet.svg` の `<style>` に元のまま残っている（使われない）
- 他の選択肢：星にまたたきのクラスを付けて、またたかせる（元の SVG にない動きになる）。**計画の前提（「星のまたたきのアニメーション」がある）と違うので、親に確認してほしい**
- 戻すときの作業：またたかせるなら、`stars.svg` の星の `<use>` にクラスを付け、またたきの CSS を `stars.svg` にも入れる（背景の画像の中の CSS アニメーションは動く）

## NF-3 惑星の大きさと置き方

- 決めたこと（レビューの必須の指摘で直した。最初の `min(50vmin, 100dvh - 20rem)` は、背の低い横向きの画面で惑星が小さすぎ、568×320 では 0 になって消えていた）：
  - 高さが十分な画面（下の横向きの低い画面以外）：惑星の箱（元の 100×100）を画面の中央に置き、見出しとボタンを箱の真下に置く（惑星が中央からずれないよう、`absolute` で箱の下につなげた）。大きさは `max(25vmin, min(50vmin, 100dvh - 16.5rem))`。見出し（32px）、間隔（24px）、ボタン（36px）、上の余白（24px）で 116px、下の余白 16px を足した 132px が、惑星の下の半分に収まる上限（`100dvh - 2 × 132px`）。下限は短い辺の 25%。環を含めた惑星は箱の約 92%、円盤は約 60% なので、ふつうの画面では環を含めて短い辺の約 46%（計画の目安 40〜50%）
  - 高さが 480px 未満で、横長（3:2 以上）で、幅が 30rem（480px）以上の画面（`max-height: 479px` かつ `min-aspect-ratio: 3/2` かつ `min-width: 30rem`。横にしたスマートフォン）：惑星の下に文字を置く場所がないので、惑星の右に見出しとボタンを並べ、惑星と文字のまとまりを画面の中央に置く。大きさは `min(60dvh, 40vw, 100vw - 22rem)`（667×375 で 225px、844×390 で 234px、568×320 で 192px）。`100vw - 22rem` は、見出しの幅（約 17rem）、間隔（2rem）、左右の余白（1.5rem ずつ）を除いた残りで、横並びが幅からはみ出さないための上限。幅 30rem 以上かつ 3:2 以上なら、この上限でも高さの 25% 以上になる
  - 再レビューの必須の指摘で直した：最初は条件が `orientation: landscape` と `max-height: 479px` だけで、480×400 や 360×340 のように横長でない低い画面でも横並びになり、見出しが右にはみ出して横スクロールが出ていた。今はそういう画面は縦に積む
  - 縦に積むときも、見出しとボタンのまとまりの幅を `calc(100vw - 2rem)` までにした（ごく狭い画面では見出しが折り返す）
- 確かめたこと：
  - E2E で、375×667・1280×800・667×375・568×320・480×400・360×340（ライトとダーク）と 844×390（ライト）で、決めた並び（横並びか縦積みか）になること、惑星が短い辺の 25% 以上（高さ 480px 以上の縦積みは 40〜50%）で中央にあること、惑星と見出し・ボタンが重ならず、全部が1画面に収まり、スクロールしないこと
  - 最初の修正の前のコードでは、667×375 で 55px（15%）、844×390 で 70px（18%）、568×320 で 0px になることを測った。再レビューの修正の前のコードでは、480×400 と 360×340 で見出しの右端が 487px、439px になり、E2E が落ちることを確かめた
  - 使い捨ての確認で、幅 280〜1400px・高さ 260〜900px を 40px 刻みで（493 通り）調べた。横スクロール、重なり、惑星が短い辺の 25% 未満になる大きさは 0。縦スクロールは、高さ 300px 以下で幅 440px 以下の画面と、幅 280px の画面（見出しが2行に折り返す）の 13 通りで出る（文字とボタンの高さが入りきらない。実際の端末でこの大きさはまれなので、このままにした）
  - 撮った画面を目で見た：最初の修正の後に 667×375・844×390・568×320・375×667・1280×800、再レビューの修正の後に 480×400・360×340（縦積み）と 568×320・667×375（横並び）
- 他の選択肢：横向きの低い画面でも縦に並べ、惑星を小さくする（568×320 では短い辺の 25% に届かない）。横並びの条件を `min-width: 36rem` にする（568×320 が縦積みになり、惑星が小さくなる）
- 戻すときの作業：`404.astro` の `--planet` と、横並びの `@media` を変える

## NF-5 `html` と `body` の背景も暗くした

- 決めたこと：レビューの任意の指摘を受け、404 ページでは `html` と `body` の背景も `#282c34` にした（`html:has(main[data-not-found])` などの全体のスタイル。ほかのページには効かない）。ライトのテーマのとき、スマートフォンでオーバースクロールしたときに白が見えないようにするため
- 戻すときの作業：`404.astro` の `<style is:global>` を消す

## NF-4 ヘッダーとフッターをなくす方法、テーマ、`<title>`

- 決めたこと：
  - `BaseLayout` に `bare` を足し、付けたページではヘッダーとフッター（とその外側の枠）を出さず、中身だけを出す。404 だけが使う。`<head>`（テーマの初期化、メタデータ、アイコン）は今までどおり
  - ライトでも暗いまま：背景と文字の色を `dark:` を使わずに直接指定した（背景 `atom-one-dark`＝`#282c34`、文字は白、ボタンは白地に `#282c34` の文字）。`html` と `body` も NF-5 のとおり
  - `<title>`（「ページが見つかりません / Page not found - unlibra」）と description は、計画の「今のまま」に従い英語を残した。画面に出る文字は日本語だけ
  - `noindex`：今の 404 ページには `noindex` の meta はなく（404 のステータスで検索に載らない）、計画の「今のまま」に従って足していない
- 戻すときの作業：`BaseLayout` の `bare` を消し、`404.astro` を前の形に戻す
