# サイト全体の多言語化の判断ログ

親が直接実装したサイト全体の日英対応（2026-10-28、ユーザーの指示）。レビューは省き、親が build、lint、format:check、`npm test`、`npm run test:e2e` と、`wrangler dev` に対するブラウザでの確認（幅 320px を含む）で確かめた。

## I18N-1 対象とURL（ユーザーの決定）

- プライバシーポリシーを除く全ページを日本語と英語にした。日本語は接頭辞なし、英語は `/en` の下。
  - トップ `/` と `/en`、活動を応援する `/donate` と `/en/donate`、クレジット `/credits` と `/en/credits`、Just HEX `/hex` と `/en/hex`、ツール `/lab/{tool}` と `/en/lab/{tool}`（既存のまま）。
- 日本語のパスから英語のパスを作る規則は `src/config/site.ts` の `localizedPath` の1か所にした（`/` は `/en`、ほかは `/en` を前に付ける）。ページは `BaseLayout` に日本語のパス（`pagePath`）を渡し、`BaseLayout` が両言語のパスを作って、hreflang と言語スイッチに使う。渡した `pagePath` がそのページの URL にならないときはビルドを止める。
- 404 ページは言語で分けない英語の1ページ（ユーザーの決定。I18N-6）。
- プライバシーポリシーは正確な表現を保つため日本語の `/privacy` だけ（ユーザーの決定）。Markdown のページは frontmatter に `lang` を必ず書く（`lang: ja`）。書き忘れはビルドを止める。

## I18N-2 Just HEX

- アプリの部分（タイトル、入力、ドック、シェアのダイアログ）は日本語のページでも英語のまま（ユーザーの指示「英語表記の要素は和訳しない」）。英語のページでは、ヘッダーとフッターも英語になる。
- 色のページも言語ごとにした（`/hex/FFFFFF` と `/en/hex/FFFFFF`）。英語のトップで色を出すと `/en/hex/FFFFFF` になり、ドックの戻るとシェアの URL も英語のページのまま。Worker は `/en/hex/*` でも動く（`run_worker_first` に `/en/hex/*` と `!/en/hex/` を足した）。
- OGP 画像は色ごとに1つで、両言語とも `/hex/FFFFFF.png`。`/en/hex/FFFFFF.png` は 404。
- Worker は色のページの hreflang（ja、en、x-default）を、その色の両言語のページに書き換える（トップのものが残らないように）。
- `src/tools/just-hex/hex.ts` は MIT のコードなので、サイトの設定（`src/config/`）を読めない（ライセンスの境界）。そこで `/hex` と `/en/hex` を `hexPaths` に自分で書き、`tests/just-hex.test.js` で `localizedPath` の結果と一致することを確かめる。

## I18N-3 言語スイッチ（ユーザーの決定と、その作り）

- メニューを開かず、同じページの別言語版へ直接移動するリンク。ワールドアイコンと、切り替え先の言語名を切り替え先の言語で表示する（日本語のページは「English」、英語のページは「日本語」。`lang` と `hreflang` も付ける）。
- 薄い枠（gray-300、ダークは gray-600）の丸角ボタン。高さは 36px、押せる範囲は `::before` で上下に 4px 広げて 44px（DESIGN.md 5.4 のコピーのボタンと同じ作り）。文字は 16px（`text-base`、前のメニューのボタンと同じ）。
- 位置はテーマ切り替えの左。
- 以前のメニュー（`data-language-switcher` のポップオーバーと「言語を切り替え」の文言）はなくした。
- 言語スイッチを出さない画面（既存の表示意図から判断）：
  - `/privacy`：英語版がないので出さない（ユーザーの指示）。
  - 404 ページ：ヘッダーとフッターのない、惑星とトップへの戻り道だけの画面（not-found）なので、スイッチは足さない。言語で分けない英語の1ページ（I18N-6）。
  - Just HEX の色の画面：色とドックだけを見せる画面（just-hex）なので足さない。トップ（`/hex`、`/en/hex`）にはヘッダーがあり、スイッチもある。

## I18N-4 モバイルのヘッダー

- 幅 1024px 未満では、メニューのボタン、サイト名（左寄せ）、言語スイッチ、テーマ切り替えの順に並ぶ。前はサイト名が中央だった。
- 幅 320px でワールドアイコンと言語名を省略せずに出すため、640px 未満ではメニューのボタンとテーマ切り替えのボタンを左右の余白に食い込ませた（`-ml-2.5`、`-mr-3`）。アイコンの端がページの左右の余白（16px）にそろい、押せる範囲は 44px のまま。並びの間隔は 4px。
- 幅 320px での実測（「English」のとき）：メニュー 6–50px、サイト名 54–161px、スイッチ 166–268px、テーマ 272–316px。横スクロールなし。文字の縮小、アイコンだけや略称への変更、テーマ切り替えの移動はしていない。
- 要確認：サイト名とスイッチの間は約 5px で、詰まって見えるかはユーザーの目で確かめてもらう。広げるには文字かボタンを小さくする必要があり、それはユーザーに相談する事項（指示のとおり独断で変えない）。

## I18N-5 サイト内リンク

- 英語のページでは、英語版があるサイト内リンクを英語版へ向けた：ロゴ（ヘッダー、モバイルのメニュー、フッター）、カテゴリのリンク（`/en#apps` など）、作品のカードの Apps のリンク、パンくずの「Home」（`/en`）、フッターの Support My Work と Credits。言語で分けない 404 の「Back to top」は `/`。
- プライバシーポリシーへのリンクは英語のページでも日本語の `/privacy` で、表記は「Privacy Policy (Japanese)」（ユーザーの指示）。`hreflang="ja"` を付けた。
- ドキュメント（docs.unlibra.com）、GitHub、BOOTH などサイトの外は変えていない。`/third-party-licenses.txt` は言語のないテキストなので、両言語から同じものにリンクする。
- `tests/layout.test.js` で、英語のページのサイト内リンクが `/en` の下か `/privacy` か `/third-party-licenses.txt` だけであることを確かめる（言語スイッチを除く）。

## I18N-6 メタデータ、サイトマップ、404

- `<html lang>`、canonical、og:url、og:locale はページの言語と URL に合わせた。hreflang は両言語と x-default（日本語のページ）。
- サイトマップは `@astrojs/sitemap` の `i18n` で各 URL に両言語の `xhtml:link` を付け、`serialize` で x-default（日本語のページ）を足した。ページの hreflang と同じ組になる。`/privacy` は代替なし。404 ページは載せない（既存のとおり）。
- 構造化データの `inLanguage` と WebSite の `url` もページの言語に合わせた。ツールの WebApplication は既存のまま。
- 404 ページ（ユーザーの指示）：言語で分けず `dist/404.html` の1つで、`/en/` の下の存在しないパスも同じページになる。表記は英語：見出し、`<title>`、description は「Page not found」、ボタンは「Back to top」で `/` へ。`<html lang="en">`。前の日本語の表記（「ページが見つかりません」「トップに戻る」、`<title>` は日英併記。not-found）はやめた。
  - 初めは言語ごとの 404（`/en/` の下は `dist/en/404.html`）を作ったが、この指示で1つに戻した。

## I18N-7 リダイレクト

- `/en` と `/en/` は `/` への 301 だったが、英語のトップになったので転送をやめた。`/en/` は静的アセットの末尾スラッシュの扱い（ほかのページと同じ 307）で `/en` に行く。
- ツールの一覧の旧 URL のうち英語のもの（`/lab/en`、`/lab/en/`、`/en/lab`、`/en/lab/`）は `/#apps` から `/en#apps` に変えた。日本語のもの（`/lab`、`/lab/ja` など）は `/#apps` のまま。
- `/ja` と `/ja/` は `/` のまま。`/lab/...` と `/en/lab/...` のツールの URL は変えていない（ユーザーの指示）。
- 既存のページの URL は変わっていないので、新しい転送は足していない。

## I18N-8 翻訳

- 日本語を正とし、英語は意味・条件・注意事項を保った自然な表現にした（ユーザーの方針）。文言は `src/messages/ja.ts` と `src/messages/en.ts`（ページ）、`src/messages/layout.ts`（ヘッダーとフッター）、`src/tools/messages/`（ツール）。`en.ts` は `SameStructure<typeof ja>` で日本語と同じキーを持つ。
- 日本語のページで英語表記の要素はそのまま（カテゴリ名、SPOTLIGHT、Just HEX、GitHub Sponsors の One-time と Monthly）。
- 既存の英訳の見直し：
  - ツールの説明文3つを書き直した。日本語にない主張（「Instantly」「multi-platform」「Boost your website's performance」など）を除き、日本語の内容（無料、一括生成、ブラウザで完結など）に合わせた。
  - フッターの説明文を日本語に合わせた（前の英文の「whatever sparks my curiosity」は日本語にない）。
  - パンくずの「Home (Japanese)」は、トップに英語版ができたので「Home」にした。
  - ツールの操作の文言（ボタン、エラー、ヒント）は意味が日本語と合っていたので変えていない。
- 活動を応援するページ：日本語のページは GitHub Sponsors に「（英語サイト）」と添えている。英語のページでは同じ意味で、Amazon（amazon.co.jp）に「(Japanese site)」と添え、GitHub Sponsors には添えない。
- 画像の代替テキスト：作品の詳細の写真は作品名（言語ごと）。カードの写真とアイコンは飾り（`alt=""`）のまま。
- 固有名の英語表記（ユーザーの確認）：
  - キャラクター名「ムルル」は「Mururu」。クレジットとムルル対応ツールのカードに出る。
  - ムルル対応ツールの英語の名前は「Mururu Blink & LipSync」（ユーザーが英名として使っているもの）。
